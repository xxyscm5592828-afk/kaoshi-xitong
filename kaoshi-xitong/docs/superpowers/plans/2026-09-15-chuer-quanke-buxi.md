## 2. 设计哲学（五角色总纲）

| 角色 | 回答的问题 | 核心原则 |
|---|---|---|
| 教育家 | 教什么 | 先修依赖溯源、跨年级诊断、Bloom 层级、元认知 |
| 名师 | 怎么补 | 错因四分类、题组变式、投入产出比优先、不死磕顽固点 |
| 脑科学家 | 怎么排 | 交错练习、指数遗忘、认知负荷、反馈时机、必要难度 |
| 心理学家 | 愿不愿用 | 自主权供给、归因训练、家长端隔离、退路机制 |
| 游戏设计 | 有没有趣 | 数据翻译成游戏语言、打击感、收敛时刻爽点 |

**两条最高哲学**：

1. **「下线更快」**：所有爽点在「攻克、销号、完成」时刻，绝不在「再来一局」时刻。KPI 是单位时间掌握度提升，不是留存时长。
2. **「翻译不贴皮」**：游戏化 = 把诊断数据翻译成游戏语言（掌握度→等级、知识点树→技能树、错题本→悬赏榜），不嫁接独立游戏。每个游戏元素必须同时服务学习目标。

## 5. 掌握度引擎 v2（✅ mastery.js 已实现）

### 5.1 作答更新（用时维度是核心差异）

```
r = actualTime / expectedTime

答对：  r ≤ 0.5   → score += 15   // 熟练/自动化（半分钟秒杀两分钟题）
        0.5<r≤1.5 → score += 8    // 已会
        r > 1.5   → score += 2    // 会但不熟练（5 分钟磨出两分钟题）
答错：  score -= 20 × 0.8^已连错次数  // 连错衰减，防一次失误毁积累
```

销号事件回写：D3 原题重做通过 +5，D7 变式通过 +8。

### 5.2 指数遗忘（替代旧线性衰减）

```
days = (now - lastReviewAt) / 86400
halfLife = 2 × 1.8^reviewCount        // 天；复习次数越多忘得越慢
score = score × 0.5^(days / halfLife)
```

### 5.3 自适应间隔（SM-2 式）

```
答对且快（r≤1）→ interval × 2.0
答对但慢       → interval × 1.3
答错           → interval 重置为 1 天
```

### 5.4 抽题优先级（投入产出比）

```
priority = [(100-score)×0.7 + 遗忘压力×0.3] × weight
60 ≤ score < 85 区间 × 1.5          // 提分最快区间
score < 30 顽固点 → 剔除出练习池，建议回炉重学
已掌握 = score ≥ 85 且 fastStreak ≥ 2 → 不再出现在突破题
```

### 5.5 溯源诊断（根因定位）

```
diagnose(kp): 沿 prerequisites 递归向上，先修 <70 视为不够牢
输出：根因点 + 溯源链 + 深度
深度 > 2 → 不练题，输出回炉重学建议（微课+教材）
练习配比 = 根因点 70% + 表层点 30%
```

## 6. 知识点树设计

### 6.1 四层结构

```
L1 册（教学日历挂载）→ L2 章（热力图聚合）→ L3 节（导航）→ L4 叶（唯一诊断单元）⭐
```

只有 L4 参与掌握度计算，上层由子节点加权聚合。**叶子颗粒度三原则**：可测量（3~5 道同类型题稳定测量）、单一性（「全等判定」拆为 SSS/SAS/ASA/AAS/HL 五点）、可讲解（一段话讲清核心）。

### 6.2 权重规则

```
weight = 中考频率(1-5) × 校内占比(1-5)，归一 1~5
广东特殊：地理、生物初二会考 → weight 整体上调 1 档
```

### 6.3 跨年级回溯

七年级不建全量树，从八年级硬依赖**反向生成**（约 150~200 核心点）。八上点薄弱 → 自动检查先修链 → 先修也弱 → 从初一补起。

### 6.4 知识点状态机 + 教学日历

```
未开学 → 已开学 → 待诊断 → [已掌握 | 巩固中(60-85) | 待突破(<60)]
                            └ 待突破 → 突破中(3-5天集中期) → 交错保持池
```

每个 L2 章挂「预计教学周」；每日优先「正在教/刚教完」章节；期中期末前 2 周自动切考试范围复习模式。

### 6.5 八科组织逻辑差异

| 科目 | 组织逻辑 |
|---|---|
| 数学/物理 | 严格按教材章节 → L4（依赖链最重，溯源最必要） |
| 英语 | Module 单元 × 三线（词汇/语法/题型技能） |
| 语文 | 按**能力点**组织（课文只是载体，诊断对象是能力） |
| 历史 | 章节时序 × 因果链 + 材料题技能 |
| 地理/生物 | 教材章节 + 读图/实验技能线（会考科，weight 上调） |
| 道法 | 单元主题 + 材料分析技能 |

完整示例（数学八上·全等三角形章 L4 展开）见附录 A.2。

## 7. 错题本「悬赏榜」（✅ wrongbook.js 已实现）

**定位**：不是收藏夹，是**销号制作战清单**。「看懂解析 ≠ 会做」。

### 7.1 销号闭环

```
D0（当天）：答错 → 自选错因 → 看解析 → 标记看懂
            （顺序不可反：先给解析会诱导假装看懂）
D3（+3天）：原题重做 ─ 通过 → D7 变式 ─ 通过 → ✅ 销号（转知识点级间隔复习）
                └ 不过 → 回解析 +3 天再重做（reappearCount+1）
D7（+7天）：变式题（同知识点同题型换数字情境）─ 不过 → 顽固错题
```

### 7.2 升级阶梯与容量

```
reappearCount = 1 → 正常再来一轮（不惩罚）
              = 2 → 自动触发知识点溯源（大概率先修漏洞）
              = 3 → 顽固清单：停止刷题，回炉建议（微课+教材章节）
活跃悬赏上限 25 道 → 超限提示「先集中补这 3 个短板知识点」
```

### 7.3 与练习流的整合（已实现于 quiz.js）

到期悬赏**必进**每日 session 且不可被踢出；**到期悬赏重做永远作为每天第一题**（见过+3 天间隔 → 正确率天然高 → 低摩擦启动 + 开局成功感）。

## 8. 教学模块（✅ lesson.js 已实现）

**定位**：补上「学」这一环。微课嵌在练习流内，不另开课堂。

### 8.1 三种教学模式

| 模式 | 触发 | 长度 |
|---|---|---|
| 错题急救课 | 答错且错因=「概念」 | ~1 分钟，直击错误那句话 |
| 回炉重修课 | 溯源定位根因 / 顽固错题 | ~3 分钟，根因完整重讲含先修衔接 |
| 热身预习课 | 教学日历下周要教 | ~2 分钟，建框架扫术语 |

另有自主点播：知识树任意点 →「给我讲讲」。

### 8.2 微课卡六段式

```
① oneLiner 核心一句话   ② problem 为什么需要它
③ analogy 类比（最重要）  ④ example 最小数字例题
⑤ pitfalls 常见坑        ⑥ check 自测 2 题（强制关卡）⭐
```

### 8.3 「最简单的话」六律（AI prompt 写死）

先说人话再上术语 / 一个类比打头 / 例题只用最小数字 / 每句一个新概念 / 类比源限定初二男生世界（游戏/打球/零花钱/乐高）/ 承认难度。

### 8.4 灵魂机制：看完 ≠ 学过

读完 5 段 → 自测 2 题 → 全对才接变式练习；有错 → **[换个讲法]**（version+1 换类比重讲：木条→乐高→GPS）。哪个类比让他一次过自测，写进理解档案——越教越对症。

## 9. AI 学长助手（⬜ 阶段 2，规格已定）

### 9.1 双层架构

```
本地触发器（何时说话，0成本，断网可用）+ AI 生成（说什么，按需调用）
消息三层：L1 纯本地模板（问候/提醒/战报数据）
         L2 本地数据 + AI 评语（周报）
         L3 全 AI（模糊问答/微课/变式题/定制笑话）
设置每日 AI 上限（默认 30），超限自动降级 L1/L2
```

### 9.2 人设

学长「阿K」（可自定义命名——命名即领养）。损友学长腔：懂梗、不说教、敢自嘲、永远站在儿子这边。助手超能力 = 三样别人不知道的上下文：教材（知识点树+教学日历）+ 你的数据（掌握度/错题/历史）+ 此刻状态（连击/疲劳）。

### 9.3 主动触发器地图

| 触发 | 行为 |
|---|---|
| 每天打开 | 开工问候（昨日表现+今日任务+考试倒计时） |
| 考前 14/7/3 天 | 提醒 + 一键切考试模式（附性价比最高复习点） |
| 知识点临界遗忘 | 「有点生锈了，5 分钟保养一下？」 |
| 连错 2 题 | 降难度 + 一句宽慰 + 冷笑话 |
| 周日晚 | 周报 + AI 评语 |
| 超 48h 未登录 | 一条召回（从不说「你怎么又不学」） |
| 里程碑达成 | 即时祝贺 |

**防骚扰红线**：每日主动消息 ≤2 条；周报 1 条；22:00 后静默；每条可 [今天跳过]。

### 9.4 模糊问答三步流水线

「y=kx那种，画出来斜斜的那条线」→ ① 本地关键词匹配知识点树，没命中 AI 分类（token 极省）→ ② 本地组装上下文（知识点卡+该生掌握度+近 2 道错题）→ ③ AI 生成（学长腔+带个人数据+末尾 [出3道题][先讲讲][懂了]）。只答知识点树覆盖范围 + 初二难度。

### 9.5 周报评语四铁律

| 情形 | ✅ 必须说 | ❌ 禁止说 |
|---|---|---|
| 进步 | 表扬具体策略 | 「你真聪明」 |
| 退步 | 拆解为可修复项 | 「退步了要加油」 |
| 平淡 | 换角度找真实亮点 | 「继续保持」 |
| 波动大 | 归因到可控因素 | 回避不谈 |

### 9.6 三层记忆系统（越用越懂你）

```
L1 事实层：每次作答/用时/对错/错因（永不丢失）
L2 画像层：本地定期计算的结构化统计
L3 理解层：AI 周期蒸馏的《理解档案》（学术/行为/心理/里程碑四维度）
```

蒸馏时机：每周日并入周报（0 额外成本）、每月深度复盘（**删除过时洞察**防偏见）、大考后校准。红线：**只记「模式和有效策略」，永不记「能力判定」**。

### 9.7 放松模块

学科梗优先（预置库 50 条轮换，0 成本）；时机：连错 2 题后 / session 超 20 分钟；频率红线：每天 ≤2 次。

## 11. 心理学设计规范（红线清单）

1. **自主权**：每日「系统推荐 + 儿子确认/调整」开工仪式；首次使用自设目标；每周一张「免死金牌」。
2. **归因训练**：文案全部「策略语言」非「特质语言」——「检查程序还没形成习惯」✅ /「你就是粗心」❌。
3. **家长端隔离**：家长视图只有周度趋势和投入天数，**永不**推送实时分数、错题明细、短板排名；分享是儿子的动作。
4. **退路机制**：连错 2 题自动降难度并插必对题（已实现）；「今天状态一般？换个轻松的」[做1道简单题] [今天到这]。
5. **反标签固化**：报告语言「距离掌握还差 12%」而非「薄弱！」。
6. **禁止交换式奖励**：不与物质挂钩；奖励过程非结果。
7. **计时器双刃剑**：练习模式计时器不可见（后台静默记录）；限时/Boss 模式可见（刻意脱敏）。
8. **启动摩擦最小化**：打开即进第一题；进度永呈「已完成 X%」框架；streak 按周结算防断链暴击。
9. **认知负荷总控**：每日 2~3 科轮换，每科 ~15 分钟，总量 45~60 分钟。
10. **睡前黄金档**：晚间练习排睡前，提示「睡前 10 分钟过一遍错题，睡眠会帮你记住」。
11. **难度心流带**：动态维持 80~85% 成功率。
12. **语气统一**：损友学长腔全局统一，AI prompt 写死。
