# 出卷增强设计（科目/知识树多选 + 掌握度差异化抽题 + 错题自动掺入）

日期：2026-10-10
状态：待用户审阅

## 1. 背景与问题

班级里老师统一出一份卷给全班做，但每个孩子对每个知识点的掌握程度不一样——已熟的知识点反复练是浪费时间，时间应该花在**不熟**的知识点上。

系统的"按掌握度差异化"已经落地三处，唯独出卷没跟上：

| 环节 | 是否差异化 | 实现 |
|---|---|---|
| 线上做题 | 是 | `Quiz.pickNext` / `pickInterleave`（含 `diagnose` 回炉剔除 + 根因加权） |
| 每日计划 / 考试冲刺 | 是（缺回炉剔除） | `Scheduler.topReviewPoints` |
| 报告「下一该攻」 | 是（缺回炉剔除） | `Report.nextTarget` |
| **出卷** | **否** | `Paper.pick()` 只按 `decay(score) < 85` 粗排 |

出卷当前的三个局限：

1. **范围只能单选**：综合 / 8 科之一，无法多选科目
2. **没有知识树选择**：不能指定"只练这几章"
3. **题源三选一（弱项/错题/随机）**：选"弱项"就完全不碰错题；且 `weak` 分支排题口径与 `Mastery.priority` 不一致

## 2. 设计

**本卷定位：个性化练习卷。** 它不是测验卷——不同孩子拿到的卷子本就不该一样，因此不做班级横向可比、不追求题型与分值的标准化。唯一目标是"把孩子有限的练题时间花在他不熟的地方"。

### 2.1 面板与默认范围（`Paper.render`）

**两种模式**（面板顶部切换）：

- **专业模式**：家长自己勾知识树、选题源、题量——**本节与 2.2 描述的就是它**
- **自动模式**：只选科目与题量，其余全自动（见 2.5）

**范围 = 一棵可勾选的知识树**（专业模式）（合一"科目多选"与"知识树多选"，只做一套逻辑）

- 树层级：**科目 → 册(L1) → 章(L2) → 节(L3) → 叶(L4)**
- 科目根节点由 `Store.subjects` 合成（`SUBJECTS` 不在知识树里，L1 的 `parentId` 为 `null`）
- 勾父含子：勾"数学"= 整科；勾某章 = 该章全选
- 顶部「全选 / 清空」+ 实时「已选 N 个知识点」（N = 生效范围内的 L4 叶总数）
- 默认展开：科目及其 L1（册）层，L2 及以下折叠；被勾选节点所在分支自动展开
- **默认范围 = 当前教学进度**：默认勾选默认科目（`SUBJECTS` 中 `default: true` 的数学）在当前教学周"正在教 / 刚教完"的章——沿用 `Scheduler.termStart` / `termWeek` 的 20 周铺排口径（实现时据章节点反查 id，不改动 `teachingChapters` 的现有返回）。假期或开学前（`termWeek(now) === 0`）→ 回退为全选
- 手动清空勾选 = 全部（保底语义，避免"空范围"无法出卷）
- **生效的"顶层范围"** = 已勾节点中**不被其它已勾节点包含者**（防父子重复计数）

**题源：三档 → 两档**

- `智能`：按掌握度抽题 + 范围内错题按规则掺入（见 2.2）
- `随机`：在选中范围内随机，不掺错题、不做倾斜、不做难度配比（仍适用"排除已做对过的原题"，见 2.2）

**题量(8/12/16)、附答案：保留不变**

### 2.2 抽题引擎（重写 `Paper.pick`）

按序执行（`智能`档）：

1. **解析范围** → 顶层范围列表（每个 = 一个勾选节点，及其下所有 L4 叶）
2. **题目池过滤**（题目级，全流程共用）：排除"近 90 天内已作答且**做对过**"的原题（数据源 `Store.attempts`；超过 90 天的明细已被 `archiveOldAttempts` 归档裁剪，故只覆盖近 90 天）。**做错过的原题保留**（仍需再练）。若某范围过滤后无题可出 → 该范围降级放开此限制
3. **错题掺入（限中段）**：仅取**选中范围内**、到期的 D3/D7 题 + 顽固错题，去重后**放在中段**（不占卷首）；上限 = `min(可掺入错题数, max(1, floor(题量/3)))`
   - **卷首 2 题固定留给"易题热身"**（`difficulty ≤ 2`，不足则以难度最低者补齐），避免一上来就卡在错题上
4. **保底**：每个顶层范围先占 1 题
   - 该范围有未掌握候选 → 取其优先级最高的点抽题
   - 该范围**全部已掌握 → 仍强出 1 题**（从该范围任取一题）
   - 该范围没有任何题目 → 跳过（不占额）
   - 若范围数 > 题量 → 按缺口从大到小取前 `题量` 个范围
5. **倾斜分配**：剩余题量按各顶层范围的**缺口权重**分配，只分给 `W > 0` 的范围
   - `W(范围) = Σ 该范围内每个 L4 叶的 max(0, 85 − 有效掌握分)`
   - 有效掌握分 = `Mastery.decay(m, now).score`；未测过默认 50 → 贡献 35
   - 若 `Mastery.isMastered(m)`（原始分口径，判定其不会被优先抽）→ 该点贡献 0
   - **温和倾斜**：对 `W` 开平方后再按比例分（`round(剩余 × √W / Σ√W)`，舍入误差补足总数）
6. **按点轮询抽题**：按 `Mastery.candidates` 返回的候选顺序**逐点轮询**（一个点取完 1 题再轮到下一个）；同时限制**同一 L4 叶 ≤ 2 题**（防单点连刷）
7. **软约束配平**（"软"= 不满足即降级，不报错）：
   - **难度配比**：易(1–2) : 中(3) : 难(4–5) ≈ 5 : 3 : 2。按三档先算目标题数再逐档取题；某档不足时把缺口让给最接近的档
   - **题型覆盖**：可用题型尽量每种 ≥1 道（与难度配比冲突时难度优先）
   - **信心锚点**：约 1/4 的题来自"有效掌握分 ≥ 60"的点，避免整卷通篇攻坚
8. 仍不足 → 用范围内其它题补足

**`随机`档**：在选中范围内随机抽 `count` 题；不掺错题、不做倾斜与难度配比，但仍适用第 2 步（排除已做对过的原题）。

**倾斜强度示例**（题量 12，范围内 2 道到期错题 → 剩 10 题；选 3 个范围）：

| 范围 | 缺口 W | 保底 | 倾斜（剩 7 题，√W 比例） | 合计 |
|---|---|---|---|---|
| A | 200 | 1 | 4 | 5 |
| B | 100 | 1 | 3 | 4 |
| C（已掌握） | 0 | 1 | 0 | 1 |
|  |  |  |  | **10** |

> 若嫌倾斜还不够温和，把指数从 0.5 调到 0.3 即可。

### 2.3 全系统口径统一

新增公共方法（`js/mastery.js`）：

```
Mastery.candidates(scopeKps, mastery, kpIndex, now) → [{ kp, p, diag }]
```

- `scopeKps`：调用方**已按科目 / 层级 / 范围筛选好的 L4 叶节点数组**（`candidates` 不感知科目与题目，只管知识点级筛选）
- 统一剔除：`isMastered` / `priority === -Infinity`（score<30 顽固点）/ `needsRelearn(depth>2)` 需回炉点
- 统一加权：先统计「根因点被指向次数」（`diag.root.id !== kp.id`），再对根因点的 `p ×1.5`
- 返回按最终 `p` 降序；**题目级**过滤（难度上限、是否已用过）不在 `candidates` 内，仍由调用方处理

四处接入（口径统一到与 `Quiz.pickNext` 一致）：

| 位置 | 回炉剔除 | 根因加权 | 判定 |
|---|---|---|---|
| `Quiz.pickNext` | 原有 | 原有 | 等价重构 |
| `Quiz.pickInterleave` | 原有 | **新增** | 行为变更 |
| `Scheduler.topReviewPoints` | **新增** | **新增** | 行为变更 |
| `Report.nextTarget` | **新增** | **新增** | 行为变更 |
| `Paper.pick` | 新功能 | 新功能 | 新功能 |

> 行为变更方向是"更贴合根因优先"的收敛：`report.js` 本就会提示"往根上挖"，`Scheduler` 考试冲刺同理应先补根。两处空结果已有兜底文案（scheduler「全科扫一遍」、report「知识树基本点亮」），剔除后仍安全。

### 2.4 卷面呈现与回录（`Paper.renderHTML` / 纸卷回录）

- **卷头增"预计用时"**：`预计用时 ≈ N 分钟`（N = `round(Σ expectedTime / 60)`，`expectedTime` 为秒）；按本卷实际抽到的题实时计算，附在现有"共 N 题"一行之后
- **卷面错题不回写错题本**：纸卷回录时**跳过"已在错题本且未销号"的题**，只把**全新做错的题**录入错题本
  - 原因：现状 `Wrongbook.onWrong` 对已存在的未销号记录会重置 `firstWrongAt` 并把状态打回「待处理」、清空 D3/D7 排程——卷面这类"抽查式"作答不应触发销号闭环重置

### 2.5 模式二：自动模式

面向不懂这些概念的家长——**只选科目与题量，其余全自动**，与专业模式共用同一抽题内核。

**面板（极简）**

- 科目：单选（`SUBJECTS` 的 8 科），默认数学
- 题量：8 / 12 / 16（同专业模式）
- 附答案：默认不勾（同现行为）
- 无知识树、无题源切换
- 一行说明文案：`按错题优先、再补齐各个知识点自动出卷；不超纲（以该科登记的"学到哪儿"为准）`

**超纲过滤（关键）**

- 复用 `Quiz.learnedKpIds()` 的口径：按该科目 `Store.unitScope[sid]` 登记的"学到哪儿"，取**顺序前缀**内的全部 L4 叶（节 > 章 > 册 三层登记；学到该节点为止，之前的都算已学）
- **未登记该科"学到哪儿"时 → 不出卷**：`learnedKpIds()` 返回 `null` 时**禁止生成**，面板提示"该科还没登记『学到哪儿』，请先到首页登记后再出卷"，并给一个跳转首页登记的入口；**不回退全科**（宁可不给，也不给超纲卷）
- 说明：`learnedKpIds()` 现按 `Quiz.subjectId()`（活跃科目）取；自动模式只针对单一科目，切到该科目后直接复用即可（如需按任意科目取，抽出为按 `sid` 传参）

**抽题（= 专业模式「智能」档的预设）**

- 错题优先：先把该科目**到期 D3/D7 + 顽固**错题纳入（去重；上限同专业模式 `max(1, floor(题量/3))`，卷面位次同 2.2——卷首 2 题易题热身、错题居中段）
- 其余名额：在"已学范围"内按掌握度**轻倾斜**铺到各 L4 知识点（同 2.2 第 5–7 步）
- 题目池过滤、卷面呈现与回录：同专业模式（2.2 第 2 步、2.4）
- 因只有单一顶层范围（该科），2.2 第 4 步跨范围保底 / 第 5 步跨范围分配退化为"科内按 L4 点倾斜"

**实现**

- 自动模式 = `Paper.pick()` 的一个预设：范围取"该科已学全部 L4"、`source` 固定 `smart`；无需另写抽题逻辑

## 4. 数据结构与接口

`Paper.state` 由：

```
{ subjectId: '', source: 'weak', count: 12, withAnswer: false, _recording: false }
```

改为：

```
{ mode: 'pro', subjectId: '', scopeIds: [], source: 'smart', count: 12, withAnswer: false, _recording: false }
```

- `mode`：`pro`（专业模式）| `auto`（自动模式）
  - `pro`：用 `scopeIds` + `source`（用户自选范围与题源）
  - `auto`：用 `subjectId`（单选科目），范围 = 该科按 `Store.unitScope` 登记的"学到哪儿"顺序前缀内的 L4 叶（`Quiz.learnedKpIds()`），`source` 固定 `smart`
- `scopeIds`：勾选的节点 id 数组；科目节点用科目 id（如 `math`），知识树节点用 kp id（如 `m8a-c11`）
- 空数组 = 全部；`source` 取值 `smart` | `random`

顶层范围判定：某勾选节点的祖先集合（科目 id + 沿 `parentId` 上溯的 kp id）中若有任一也被勾选，则该节点被包含，不算顶层范围。

## 5. 交互细节

- 树展开/折叠状态存内存（默认展开规则见 2.1），刷新即收起
- 勾选/取消由 `candidates` 之外的轻量重渲完成（复用现有 `this.render(el, back)` 模式）
- 已选计数与预览题目列表实时更新
- 抽题规则以一行说明呈现在预览区（"错题居中段、前 2 题热身、同一知识点最多 2 题、难度约 5:3:2"），让用户理解卷面为何这样排布；具体规则见 2.2
- 科目标签：多科目时卷面每题标注科目（沿用现状 `showSubj`），单科目不标

## 6. 测试计划

- 底线：`node --test tests/*.test.js` 全绿（当前 321）
- 新增 `tests/paper.test.js`：
  1. 顶层范围解析：勾父含子；父子同勾只计父
  2. 默认范围：默认勾选数学当前教学周"正在教/刚教完"的章；`termWeek === 0`（假期/开学前）回退全选
  3. 题目池过滤：近 90 天内做对过的原题被排除，做错过的保留；某范围过滤后无题时降级放开
  4. 卷首热身：前 2 题为 `difficulty ≤ 2`（不足则以难度最低者补齐）
  5. 错题掺入：仅掺**选中范围内**的到期 D3/D7 + 顽固错题，放在**中段**（不占卷首）；上限 `max(1, floor(题量/3))`；`random` 档不掺
  6. 保底：多范围各 ≥1 题；熟范围也强出 1 题；范围数 > 题量时按缺口从大到小取前 N
  7. 倾斜：缺口大的范围分到更多题（√W 压缩后）
  8. 每叶上限与轮询：同一 L4 叶 ≤ 2 题，逐点轮询不单点连刷
  9. 软约束降级：难度配比易:中:难 ≈ 5:3:2、某档不足时让给最接近的档不报错；题型尽量每种 ≥1 道；信心锚点约 1/4 题来自"有效掌握分 ≥ 60"的点
  10. `Mastery.candidates`：剔除已掌握 / <30 / 需回炉；根因点 ×1.5；不掺入题目级过滤
  11. `random` 档：限定在选中范围内、不掺错题，仍排除已做对过的原题
  12. 卷面：预计用时 = `round(Σ expectedTime / 60)`；回录跳过已在错题本未销号的题、只录全新做错的题
  13. 自动模式·范围：题源固定 `smart`、范围 = 该科按 `unitScope` 登记的"学到哪儿"顺序前缀（`learnedKpIds()`）；未登记时（返回 `null`）**不出卷**并给出登记引导，不回退全科
  14. 自动模式·抽题：该科到期 D3/D7 + 顽固错题优先纳入（去重、上限 `max(1, floor(题量/3))`、居中段），其余名额在已学范围内按掌握度轻倾斜铺到各 L4 点；不出试卷外题
- 行为变更回归：`Scheduler.topReviewPoints` 与 `Report.nextTarget` 新增回炉剔除 + 根因加权后，跑全量确认现有 `tests/report.test.js`（4 条 `nextTarget`）不破（seed 无先修链，不触发加权）
